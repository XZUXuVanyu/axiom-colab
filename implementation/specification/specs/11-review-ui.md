# 11 图形界面与交互

Qt Widgets 主窗口四个入口：工作区、工具库、项目协作、验证与运行。库是用户级独立入口。工作区内含目标/计划、对象和实验画布。用户看到名称、版本、状态、下一动作；hash、原始JSON、ABI和日志放可展开详情，不把内部状态码充当主文案。

ProjectPanel支持目录绑定、源码列表、上下文导出、提案diff、冲突、应用、打开VS。证据页分作者/公共/私有/人工集成，显示真实passed/failed/incomplete/awaiting_user。用户批准面板显示准确设计或包版本、文件差异、权限、必要测试、未解问题；按钮只有在该对象状态合法时可用，host仍再次检查。

图画布固定采用QGraphicsScene/QGraphicsView自绘节点/端口/贝塞尔边，不引入第三方节点库。支持拖动连线、非法目标预览、断线、删除节点、平移缩放、参数侧栏、Run/Cancel、节点状态、结果详情和单层组合封装。允许保存view state但不得混入graph语义hash。删除节点列出将删除连线，并可在草稿中撤销；不改历史run。

数值参数显示单位和合法范围，非法输入显示错误且禁run；不静默改为最接近合法值。已接线输入不编辑literal，断线恢复先前有效值。双击原子打开源码定位，双击组合查看内部图；V1仅查看内部已发布版本，修改须复制为新草稿。

长任务非阻塞，进度未知显示忙碌但不伪造百分比。run结果标graph revision，UI修改草稿后旧结果带“来自上一版本”标识。关闭窗口不隐式批准，关闭host需说明活动作业并给用户取消/保持运行选择。

界面命令只经HostClient；不直接打开SQLite/库目录，不直接启动worker。模型接口不会通过UI代码复用取得review secret。普通鼠标拖动没有网络、设备写入、文件导出或自动执行副作用。

最少实际检查：窗口缩放到1280×720可操作；DPI100/150/200%文本不裁切；中文/带空格项目路径；后台作业期间拖动画布；连接非法单位；运行中修改草稿；冲突diff保留用户文件。截图只证明UI状态，不代替后台测试。
